# 📱 Calculator Web App

A simple and responsive calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean and modern UI.

---

## 🚀 Features

* Basic operations: ➕ Addition, ➖ Subtraction, ✖️ Multiplication, ➗ Division
* Percentage (%) support
* Clear all (AC) functionality
* Delete last digit (DEL)
* Responsive and minimal UI
* Real-time input display

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the app
* **CSS3** – Styling and layout
* **JavaScript (Vanilla JS)** – Functionality and logic

---

## 📂 Project Structure

```
calculator/
│── index.html     # Main HTML file
│── style.css      # Styling
│── script.js      # Functionality
```

---

## 💻 How It Works

* User clicks buttons to input numbers and operators
* Input is stored as a string
* When '=' is pressed, the expression is evaluated using JavaScript
* 'AC' clears the entire input
* 'DEL' removes the last character

---

## ⚠️ Note

This project uses JavaScript's `eval()` function for calculation. While it works for basic functionality, it is not recommended for production-level applications due to security concerns.
